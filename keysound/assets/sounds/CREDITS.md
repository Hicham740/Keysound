# Sound credits and licensing

The 12 WAV files in this folder are **user-supplied samples** bundled with the
KeySound arsenal profile. Their author, original source URL and licence have
not been confirmed, so every field is recorded as `unknown` in
`manifest.json`.

**Before redistributing KeySound or these sound files, confirm the licence of
each sample with the person or site it came from.**

The KeySound application code is MIT-licensed (see the repository `LICENSE`).
The legacy generator in `tools/generate_sounds.py` is project code; it does not
produce the files currently shipped in this folder.
