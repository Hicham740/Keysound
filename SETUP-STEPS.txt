================================================================================
KEYSOUND - TERMINAL SETUP STEPS
================================================================================
Project folder: /home/hicham/Desktop/projects/shotgunkeyboard

Follow these steps in order. You only need to reboot/log out once, in step 2.
BEFORE YOU REBOOT, run step 2 first. Steps 1 and 3 can be done any time.

--------------------------------------------------------------------------------
STEP 1 - TRY THE APP RIGHT NOW (optional, takes 10 seconds)
--------------------------------------------------------------------------------
Open a terminal and run:

    cd /home/hicham/Desktop/projects/shotgunkeyboard
    python3 -m keysound

The window opens and uses the X11 fallback. Type anywhere to hear sounds.
Mute/unmute with:  Ctrl+Alt+Shift+M
Close the window to hide it in the tray.

If you only want to see it working, stop here.

--------------------------------------------------------------------------------
STEP 2 - ENABLE THE RECOMMENDED evdev BACKEND (DO THIS BEFORE REBOOTING)
--------------------------------------------------------------------------------
This needs your sudo password once. Run:

    cd /home/hicham/Desktop/projects/shotgunkeyboard
    sudo ./scripts/setup-kali.sh

What it does:
  - installs the runtime packages (GTK3, PyGObject, numpy, PulseAudio libs);
  - adds your user "hicham" to the "input" group;
  - prints a privacy warning.

When it finishes, it will tell you to log out and back in. Do that now:

    Reboot the machine, or log out of the desktop and log back in.

The group change does NOT take effect until you do this.

--------------------------------------------------------------------------------
STEP 3 - AFTER LOGGING BACK IN: CHECK evdev ACCESS
--------------------------------------------------------------------------------
Open a terminal and run:

    groups | tr ' ' '\n' | grep input

You should see:

    input

If you see it, start the app:

    cd /home/hicham/Desktop/projects/shotgunkeyboard
    python3 -m keysound

The yellow "XInput2 fallback" banner should now be gone. Direct evdev is active,
which also works on Wayland.

To confirm with the diagnostic command:

    cd /home/hicham/Desktop/projects/shotgunkeyboard
    python3 -m keysound --diagnose

Look for:

    "evdev": { "permission_ok": true, ... }

--------------------------------------------------------------------------------
STEP 4 - INSTALL AS A NORMAL SYSTEM APP (optional)
--------------------------------------------------------------------------------
Install the already-built Debian package:

    cd /home/hicham/Desktop/projects/shotgunkeyboard
    sudo apt-get install -y ./dist/keysound_1.0.0_all.deb

Then start it like any other app:

    keysound

or launch "KeySound" from the application menu.

After installing, the setup helper is also available at:

    sudo /usr/share/keysound/setup-kali.sh

(You only need this if you installed the .deb on a different machine or skipped
step 2.)

--------------------------------------------------------------------------------
STEP 5 - VERIFY EVERYTHING (optional)
--------------------------------------------------------------------------------
Run the test suite:

    cd /home/hicham/Desktop/projects/shotgunkeyboard
    python3 -m unittest discover -s tests -t . -v

Expected result: "Ran 57 tests ... OK".

Run the environment check:

    python3 -m keysound --diagnose

Expected highlights:
    "sounds": 24
    "audio": { "running": true }
    after step 2: "evdev": { "permission_ok": true }

--------------------------------------------------------------------------------
STEP 6 - USE THE APP
--------------------------------------------------------------------------------
  - Click any key on the visual keyboard to assign a sound to that key.
  - Use the "Groups" tab for whole-category fallbacks (letters, digits, etc.).
  - "Default fallback" under the keyboard is used when a key and its group are
    both silent.
  - "Hold to repeat", "Modifier keys", and "Start at login" are in the control
    bar at the top.
  - Mute/unmute anywhere with:  Ctrl+Alt+Shift+M
  - Settings are saved automatically to:
        ~/.config/keysound/settings.json
  - The tray icon has Open, Armed, Mute, Start at login, Test sound, Input
    status, and Quit.

--------------------------------------------------------------------------------
IF YOU DO NOT HAVE THE SUDO PASSWORD
--------------------------------------------------------------------------------
Skip step 2. The app still works on this X11 desktop using the automatic
XInput2 fallback. Only Wayland and direct evdev access require the "input"
group.

--------------------------------------------------------------------------------
TROUBLESHOOTING
--------------------------------------------------------------------------------
No sound?
    Check master volume and mute state, then run:
        python3 -m keysound --diagnose
    "audio.running" must be true.

Still see the yellow fallback banner after reboot?
    Run the group check again:
        groups | tr ' ' '\n' | grep input
    If "input" is missing, run step 2 again and make sure you fully logged out
    (not just locked the screen).

Wayland shows no input backend?
    Join the "input" group (step 2) and re-login. evdev is the Wayland path.

Tray icon missing?
    Your desktop needs an AppIndicator/StatusNotifier host. The app still works;
    run it with --no-tray if closing the window should quit it.

Need the full technical details?
    Read IMPLEMENTATION_REPORT.txt in this folder.
